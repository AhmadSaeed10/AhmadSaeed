approach:
  - title: Brand and layout first
    text: Designed the logo, brand and page layouts before writing any code, so the build follows a settled design.
  - title: Built in Astro
    text: Astro ships almost no JavaScript by default, so pages stay light even with the animation the brand called for.
  - title: Claude Code as build partner
    text: Claude Code writes and edits the site, from new sections to copy changes and layout tweaks.
  - title: GitHub and Vercel
    text: Every change goes to GitHub, so nothing is lost and everything is reviewable. Vercel deploys each push automatically, so updates go live in minutes.
  - title: Content in simple files
    text: Page content lives in simple files, so customising a page is a request, not a rebuild.
  - title: Measured from day one
    text: Set up GA4 with custom events and Google Search Console, so content is shaped by real data on what people search, what they read and where they drop off.
